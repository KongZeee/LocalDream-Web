## 2. 后端依赖（Python，无 requirements 文件，按 README 安装）

| 包 | 最低版本 | 用途 | 使用位置 |

| `torch` | ≥ 2.0.0 | 推理框架 | generator / upscaler / system |

| `fastapi` | ≥ 0.100.0 | Web 框架 | main + 全部 routes |
| `uvicorn` | ≥ 0.20.0 | ASGI 服务器 | run.py |
| `aiosqlite` | ≥ 0.19.0 | 异步 SQLite | db.py + model/history 服务 |
| `diffusers` | ≥ 0.25.0 | SD/SDXL pipeline 与调度器 | generator |
| `transformers` | ≥ 4.30.0 | 文本编码器等 | diffusers 间接 + generator shim |
| `accelerate` | ≥ 0.20.0 | 模型加载加速 | diffusers 加载路径 |
| `safetensors` | — | 安全权重格式 | pipeline `use_safetensors=True` |

### 可选 / 隐式

| 包 | 用途 | 缺失时行为 |
|----|------|-----------|
| `huggingface-hub` | `snapshot_download` 模型下载 | 仅 `POST /api/models/download` 报 500，其余功能正常 |
| `numpy` | 超分图像数组转换 | 仅 RealESRGAN 路径需要；自动降级 LANCZOS |
| `basicsr` + `realesrgan` | RealESRGAN 超分管线 | `upscale_image` 降级为 Pillow LANCZOS 4x |
| `psutil` | CPU 内存统计 | system 路由回退 Win32 ctypes |
| `pydantic` | 请求模型校验（FastAPI 自带依赖） | — |

> 版本兼容注记：peft ≥ 0.14 与 transformers 4.42 组合需要 generator.py 顶部的 `EncoderDecoderCache` shim；`_patch_transformers.py` 是针对旧版 transformers safetensors metadata 的本机补丁脚本。

## 4. 前后端接口契约（耦合点）

前端 `utils/api.ts` 与后端 routes 一一对应，改动任一侧需同步另一侧：

| 契约 | 前端 | 后端 |
|------|------|------|
| 生图 SSE 事件（started/progress/complete/error） | `generateImage()` 解析器 | `generate_image()` 事件流 |
| `GenerateRequest` 字段 | TS 接口 | Pydantic 模型 |
| LoRA spec `{id,name,path,filename,weight}` | `activeLoras` 映射 | `apply_loras()` 消费 |
| 历史图片相对 URL `/api/history/{id}/...` | 拼接 `api_base_url` | `get_history()` 生成 |
| 设置键名（default_steps 等） | `AppSettings` 接口 | settings 表 |

## 5. 外部资源依赖

| 资源 | 用途 | 引用位置 |
|------|------|---------|
| HuggingFace Hub | 模型下载、非本地 model_id 在线加载 | model_manager / generator |
| `madebyollin/sdxl-vae-fp16-fix` | SDXL 修复版 VAE（首次用到时从 HF 拉取并缓存） | generator（两处） |
| Google Fonts（Orbitron / JetBrains Mono） | 前端字体 | index.html |
| 本地 SD 模型权重 | 用户自备，放 `data/models/` | — |
| RealESRGAN 权重 | 用户自备（超分可选） | upscaler |

> 离线注意：SDXL 路径依赖 `sdxl-vae-fp16-fix` 联网首拉；前端字体 CDN 失败会回退系统字体，不影响功能。
